## Machine Learning Jupyter Notebooks

This repository contains implementations of core machine learning algorithms using NumPy, focusing on building intuition for how they work internally.

## Implemented Algorithms

- Linear Regression
- Logistic Regression
- Neural Networks
- PCA
- K-Means
- SVM


Each notebook explores implementation details, optimization strategies, and practical considerations involved in building machine learning algorithms from scratch.

This work was inspired by the amazing Machine Learning course taught by Andrew Ng. Some implementation ideas were influenced by the python adaptation created by [dibgerge](https://github.com/dibgerge/ml-coursera-python-assignments). The code challenges I organized in this repository are for learning purposes.

For running this environment, conda is being used.
